# 生电服飞行系统
玩家通过在线与正常游玩积累活跃度，并根据活跃等级获得不同的飞行兑换比例。  

## 一、玩家命令  
```
/tfly
/tfly on 启用飞行
/tfly off 关闭飞行
/tfly activity 查看活跃度
/tfly activity detail 查看具体活跃度
```
 `/tfly activity detail `可以查看自己的详细活跃度、各项统计分数、衰减结果、多样性系数和当前等级。

## 二、计算流程：
### 1、原版数据加权计算
活跃度会从战斗、生产、互动、探索四个方面加权计算玩家的原版统计数据  
| 类别 | 统计项目 | 权重 |
|------|----------|------|
| 战斗 | 击杀生物 | ×1 |
| 战斗 | 击杀玩家 | ×0 |
| 战斗 | 造成伤害 | ×0.2 |
| 战斗 | 承受伤害 | ×0.5 |
| 战斗 | 死亡次数 | ×10 |
| 生产 | 挖掘方块 | ×0.5 |
| 生产 | 使用/放置物品 | ×0.2 |
| 生产 | 损坏物品 | ×10 |
| 生产 | 合成物品 | ×0.2 |
| 生产 | 拾取物品 | ×0.02 |
| 生产 | 丢弃物品 | ×0 |
| 互动 | 附魔物品 | ×10 |
| 互动 | 钓到物品 | ×5 |
| 互动 | 与村民交易 | ×1 |
| 互动 | 繁殖动物 | ×2 |
| 互动 | 赢得袭击 | ×25 |
| 探索 | 移动距离（千米） | ×5 |
| 探索 | 游戏时间（小时） | ×100 |

### 2、衰减与防刷机制  
单个统计项目的加权分数在不超过 100,000 时正常计算；超过后开始进行对数衰减：
```
有效分数=100000+100000×ln[1+(加权分数- 100000)÷100000]
```
这意味着随着单项统计量变大，继续刷取的收益会逐渐降低。  

### 3、多样性计算：  
每类有效分数达到100才算一个有效类别，并根据玩家参与内容的多样性应用系数：  
0类 ×0.20  
1类 ×0.65  
2类 ×0.80  
3类 ×0.92  
4类 ×1.00  

### 4、最终活跃度计算  
最终活跃度还受到在线时长上限限制：  
```
活跃度上限=10000+累计在线小时×1200
最终活跃度=min(衰减及多样性处理后的分数, 活跃度上限)
```
因此，仅依靠短时间内大量刷取统计数据，无法立刻成为老玩家。

## 三、玩家等级与飞行比例
| 玩家等级 | 活跃度要求 | 在线时间兑换飞行 |
|----------|------------|------------------|
| 新玩家 | 0 | 在线15分钟＝飞行1分钟 |
| 普通玩家 | 30,000 | 在线10分钟＝飞行1分钟 |
| 活跃玩家 | 80,000 | 在线6分钟＝飞行1分钟 |
| 高活跃玩家 | 150,000 | 在线3分钟＝飞行1分钟 |
| 老玩家 | 200,000 | 在线1分钟＝飞行1分钟 |

## 四、飞行时间规则
- 系统会读取玩家已有的原版累计游戏时间，不需要重新开始计算。
- 不需要手动兑换，飞行时间会根据当前活跃等级实时计算。
- 等级或兑换比例发生变化后，可用飞行时间也会立即重新计算。
- 开启飞行但站在地面时不会扣除时间。
- 玩家真正离地飞行时才会消耗在线时长余额。
- 飞行期间不会同时积累新的在线时长余额。
- 退出服务器时会自动关闭飞行模式，但剩余余额不会丢失。
- 剩余飞行时间会通过 Boss 血条实时显示。
