# 服务器相关

### 机器配置:

- CPU:9950X
- 运行内存:32G
- 储存:350G SSD
- 宽带:300mbps

运行状态详见 [新亭泪服务器状态监测](https://xintinglei.cn/status.html)

### 互通原版增强生电服:

- 核心 `Java Fabric 1.21.4`
- 种子 `4460962376475996898`
- 目前支持纯原版`1.20.1-26.3`、`Fabric1.20.1-26.3`、`专用生电客户端`、基岩版`26.0-26.45`
- 该服正常情况下不换档
- 生电服修改了`矿车`在`沙砾方块`上的限速，可以让矿车加速到`更高的速度`  

**Fabric兼容性说明：**
1. 对于**非1.21.4的客户端**，建议只安装群文件中的生电服跨版本兼容协议模组(支持1.20.1-26.3)、纯客户端优化、HUD美化、辅助模组，不建议安装其他需要服务器支持的模组
2. 对于**1.21.4的客户端**，可用**Fabric API＋生电服跨版本兼容协议模组＋可选优化与辅助模组**，或还可以在此基础上安装额外安装**XintingleiExtras+Centifolia**
### 整合包服

- 现整合包：**农场物语v1.5.2fix2** （整合包会定期更换）
- 需要使用对应客户端登录（见群文件与群公告）
- 不支持基岩版游玩
- 增加了应用能源2，ysm，暮色风味乐事，喷气背包，AE2无线终端，暮色森林模组，需要下载群文件中的暮色森林兼容补丁`twilight-lobby-fix`
  
### 小游戏服
