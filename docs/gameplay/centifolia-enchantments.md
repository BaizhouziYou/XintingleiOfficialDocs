# 生电服专属附魔玩法

Centifolia（百叶）是新亭泪的专属玩法 Mod，为生电服添加专属附魔与战斗机制。生电服客户端已包含与其配套的客户端表现；具体数值、触发条件与平衡调整以游戏内当前版本为准。

### 弓与弩

- **专注**：应用于弓，延长拉弓时间至五秒，以弓的寿命换取极高的单发伤害

- **破晓**：应用于弓，需求专注为前置附魔，让弓可以进行二段蓄力，持续蓄力时脚下会出现金色粒子，十秒蓄力后，释放贯穿天际的箭矢，同时强制使弓的耐久降低为1

- **连射**：应用于弩，当你装填箭矢后，可以长按左键进行连续射击（大人，时代变了）

### 近战与伤害

- **会心**：应用于剑，右键可横剑格挡一次攻击（不可格挡远程攻击），招架成功后获得少量攻击加成

- **回响**：应用于剑，使古城沉寂的音波沿剑锋回响，你的攻击附带监守者同款音波  注：与会心、余烬冲突

- **余烬**：应用于剑，需求火焰附加为前置附魔，你可以长按右键对剑进行充能，随后强化三次攻击，若成功命中会对前方扇形区域施加爆燃，火焰灼烧造成伤害的速度加快  注：与会心，回响冲突

- **狂暴**：应用于斧头，每当你跳劈暴击命中时，你的攻击冷却会缩短，同时获得少量的攻击加成，最高可叠加8层

### 生存与装备

- **鳃化**：应用于头盔，需求水下呼吸为前置附魔，进入水中后，你的肺会逐渐转化为鳃，当完全转化后，氧气条会消失，你可以在水中自由呼吸。但当你离开水一段时间后，你的鳃会因为不适应陆地而导致你窒息，在你的鳃重新转化为肺前你将持续受到窒息伤害

- **重装**：应用于盔甲四件套，当你的盔甲都带有重装时，你受到的伤害会大幅降低，同时你的行动将会变得极为沉重

- **熔岩行者**：应用于靴子，在岩浆上行走时会留下持续一段时间的岩浆块，同时免疫岩浆块对你的伤害

- **动力推进**：应用于靴子，当你在跳跃后的四十刻内再次按下疾跑键，可向指定方向喷气冲刺 （谁家威龙？）

### 特殊

- **磁铁**：将掉落物拾取范围扩大至原版的三倍（王晓婷！）

- **诚实**：不要把带有此附魔的铁斧扔进河里

## 七宗罪诅咒

七宗罪系列会以红色诅咒附魔显示，只能从战利品书或战利品装备中获得；它们不会出现在附魔台或村民交易中。

- **怠惰诅咒**：应用于剑、斧头、镐子、锄头、铲子   使你的攻击与使用都变得迟缓

- **贪婪诅咒**：应用于剑、斧头、镐子、锄头、铲子   随机增加你击杀生物与挖掘方块所掉落物品的数量，最高可达20倍率，但代价......

- **傲慢诅咒**：应用于盔甲，需求你的盔甲携带纹饰，当集齐四件套时，你的攻击+1、受到的伤害-1，受到伤害后效果消失，十秒后重新获得该效果  (哦先生，这很体面)

- **色孽诅咒**：应用于盔甲，携带此诅咒的护甲无法被装备，当你穿上时会被强制脱下  （哪个神人想出来的？）

- **嫉妒诅咒**：应用于盔甲，集齐四件套后你将嫉妒各种存在（包括虚空），在你死亡后，会触发亡语，会从你嫉妒的存在身上窃取一件物品

注：嫉妒带回的装备会成为“赝品”。赝品可以正常使用、放入容器，但不能用铁砧、附魔台、砂轮、锻造台、等工作方块修改与修复，同时经验修补附魔也会被自动移除

- **暴怒与暴食诅咒**：因为没有好的想法暂不加入，如果你有好想法请联系Rosa，我会进行参考并在管理组审核通过后进行实现

## 玩法提醒

- 动力推进、冷却、位移与耐久消耗均由服务器结算；客户端不会自行决定效果是否生效。
- 贪婪的额外掉落受全服生成上限约束，超过上限或拥有者断开连接时，尚未生成的额外掉落可能被舍弃，俗称吞物品（贪得无厌者终将一无所有，才不是不知道怎么修复呢）

::: tip
客户端已经包含 Centifolia 的必要组件。若附魔名称、特效或 HUD 显示异常，请先检查是否使用了最新版本
:::
