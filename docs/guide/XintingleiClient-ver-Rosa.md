# Xintinglei客户端

Xintinglei客户端是面向新亭泪生电服玩家整理的 Windows 整合包。它已配好游戏版本、常用 Mod、资源包、PCL 主页与服务器相关基础内容；正常情况下，不需要自行拼装 Mod 或额外导入整合包。

## 版本信息

| 项目 | 内容 |
| --- | --- |
| 当前版本 | Rosa v1.1.2 |
| 游戏版本 | Minecraft 1.21.4 |
| 加载器 | Fabric Loader 0.19.3 |
| Java | Java 21 |
| 适用平台 | Windows |
| 启动器 | Plain Craft Launcher（PCL） |
| 客户端版本名 | `XinTingLeiClient-Rosa-V1.1.2` |

::: tip 请从新亭泪群文件处获取当前客户端
:::

## 客户端包含什么

- 面向 Minecraft 1.21.4 Fabric 的基础运行环境；
- 性能、界面、背包、地图、建造与生电辅助等常用组件；
- 新亭泪皮肤站登录所需的基础配置；
- 新亭泪服务器预设与 PCL 联网主页；
- Centifolia客户端组件，用于显示服务器的专属附魔、动画、HUD、粒子与音效；
- 全方位汉化与新亭泪特调菜单彩蛋文本

部分不随包分发的组件会由 PCL 主页提供一键下载与校验。首次使用时，请按[安装教程](/guide/xintinglei-client-installation)完成这一步。

## 使用建议

保持默认配置即可正常游玩。若出现启动失败、显示异常或缺少 Mod 的提示，不建议自行删除 `mods`、`config` 或资源包内的文件；请先保留报错信息，你可以发送给ai（不要使用豆包）或者发送到qq群内寻求技术指导

想了解服务器新增的附魔与专属机制，请阅读 [生电服专属附魔玩法](/info/centifolia-enchantments)。
