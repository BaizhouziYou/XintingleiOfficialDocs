# 入服步骤

1.通过新亭泪的审核

2.使用[新亭泪皮肤站](https://skin.xintinglei.cn/)注册你的皮肤站账号
 >注册时需要邀请码，qq私信找管理要一个就行 
 > 
 >注册时务必与你原本的游戏id一致(不论正版/离线)

3.**java版入服**  
启动器登录皮肤站（下面以pcl为例）
- 打开pcl2-版本设置
- 划到服务器一栏
- 选择登录方式：**第三方认证：Aushlib Injector或LittleSkin**
- 将皮肤站的 **Yggdrasil API 认证服务器地址**填入认证服务器
- 在启动器主界面登录你的皮肤站账号  

**基岩版入服**  
下载可前往[基岩版下载站](https://mc.minebbs.cn/)  
需使用以下版本中的任意基岩版登录  
```
1.26.0 ～ 1.26.3  
1.26.10  
1.26.20 ～ 1.26.23  
1.26.30 ～ 1.26.34  
1.26.40 ～ 1.26.45  
```
在你首次加入服务器的时候会提供一个8位数的绑定验证码，你需要使用它在[基岩版皮肤站绑定](https://skin.xintinglei.cn/user/bedrock-link) 完成绑定

4.在群文件中下载你想游玩的子服的整合包并拖入启动器  
- 如果你下载了[Xintinglei客户端rosa特调](https://docs.xintinglei.cn/guide/XintingleiClient-ver-Rosa.html)可以免去填写认证服务器与下载生电整合包的步骤
- 亡者世界需要往再加几个模组，注意看群公告
- 基岩版忽略此步

5.群公告找到服务器地址并填入游戏中  
（亡者世界端请忽视自带两个服，仍需填服务器地址）

6.获取验证码并在q群里发送 `绑定xxxx`

7.进入大厅服后点击NPC进入你想游玩的子服 **（整合包服需要点击NPC回到服务器列表后重进）**
